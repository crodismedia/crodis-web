¿Cómo aparecen los talleres de Pego en esta página?

Se muestran las fichas activas cuya población publicada coincide con Pego.

¿El código 03102 es un código postal?

No. Es el código municipal incluido en el listado utilizado para crear esta página.

¿Puedo registrar un nuevo taller de Pego?

Sí. El formulario de alta permite publicar los datos públicos del negocio y sus servicios.
